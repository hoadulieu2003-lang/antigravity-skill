# Product and UI verification

Verify requirement and role coverage, end-to-end task completion, navigation, permissions, empty/loading/error/success states, realistic data, responsive behavior, accessibility, consistency, and recovery from mistakes.

Use representative user tasks rather than checking screens in isolation. Separate objective failures from aesthetic preferences. A visual defect is release-blocking only when it violates an agreed criterion or materially harms comprehension, trust, accessibility, or task completion.
