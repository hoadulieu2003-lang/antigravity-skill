# gltfjsx Pipeline Reference (`3D Model Code Compilation`)

> Turns GLTF/GLB models into reusable, typed React Three Fiber JSX components.

## 1. CLI Usage

Run via `npx` directly without global installation:

```bash
# Basic conversion
npx gltfjsx model.glb

# Production flags (Recommended)
npx gltfjsx model.glb --transform --types --shadows
```

### Key CLI Flags:
- `--transform` / `-T`: Optimizes geometry using gltf-transform, deduplicates textures, compresses with WebP / KTX2, and Draco. Shrinks file size by 70–90%!
- `--types` / `-t`: Emits full TypeScript interfaces for all nodes and materials.
- `--shadows` / `-s`: Adds `castShadow` and `receiveShadow` to every mesh automatically.
- `--precision` / `-p`: Sets floating point number precision (e.g., `-p 3` reduces bundle size).

## 2. Typical Output Structure

```tsx
import React, { useRef } from 'react';
import { useGLTF } from '@react-three/drei';
import { GLTF } from 'three-stdlib';
import * as THREE from 'three';

type GLTFResult = GLTF & {
  nodes: {
    Cube: THREE.Mesh;
    Sphere: THREE.Mesh;
  };
  materials: {
    PaintMaterial: THREE.MeshStandardMaterial;
    ChromeMaterial: THREE.MeshStandardMaterial;
  };
};

export function Model(props: JSX.IntrinsicElements['group']) {
  const { nodes, materials } = useGLTF('/model-transformed.glb') as GLTFResult;

  return (
    <group {...props} dispose={null}>
      <mesh
        castShadow
        receiveShadow
        geometry={nodes.Cube.geometry}
        material={materials.PaintMaterial}
        material-color="royalblue" // Easy material property override
      />
      <mesh
        castShadow
        receiveShadow
        geometry={nodes.Sphere.geometry}
        material={materials.ChromeMaterial}
      />
    </group>
  );
}

useGLTF.preload('/model-transformed.glb');
```

## 3. Best Practices with gltfjsx
1. **Always place transformed assets in `/public`**: The resulting `.glb` file should live in the public web root.
2. **Material Overrides**: You can change any material property directly as a JSX prop: `<mesh material-roughness={0.1} material-color="#ff0000" />`.
3. **Interactive Sub-meshes**: Attach `onClick` or `onPointerOver` to individual sub-meshes generated by gltfjsx to trigger specific UI actions.
