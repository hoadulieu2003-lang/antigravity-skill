# Automation definition

Use this adapter for scheduled, event-driven, browser, integration, or operational workflows.

## Required analysis

- Define triggers, preconditions, actions, outputs, schedules, actors, and permissions.
- Define state transitions, duplicate-event behavior, idempotency, concurrency, rate limits, timeouts, and retry policy.
- Identify external dependencies, credential boundaries, side effects, and actions requiring human approval.
- Define partial-failure recovery, rollback or compensation, manual override, audit trail, alerting, and ownership.
- Distinguish a safe retry from repeating an irreversible external action.

## Definition additions

Add trigger-action contract, state model, dependency map, authorization boundary, retry and recovery rules, observability, human intervention points, and acceptance scenarios.
