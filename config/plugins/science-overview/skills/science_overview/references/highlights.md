# Antigravity for science highlights

Curated highlights, newest first. For more use cases and demos, see
https://antigravity.google/use-cases/science

## Cheminformatics (2026-11-03)

New cheminformatics skills to speed up drug discovery workflows. Available in
the **Chemistry** plugin.

-   Blog:
    https://deepmind.google/blog/agentic-cheminformatics-with-google-antigravity/
-   Demo: https://youtu.be/afQqqcmLUWw

## Biomolecular Structure Viewer (2026-10-15)

An interactive 3D structure viewer inside Antigravity, launched with the
antimicrobial peptide discovery case study. Available in the **Structural
Biology** plugin.

-   Blog: https://deepmind.google/blog/accelerating-antimicrobial-discovery/
-   Demo: https://youtu.be/JDyatKs10Kk

## AlphaGenome Atlas skills (2026-09-08)

Skills for exploring AlphaGenome Atlas, a predictive map of every possible
single-letter DNA change in the human genome. Available in the **Genomics**
plugin.

-   Blog:
    https://deepmind.google/blog/alphagenome-atlas-a-predictive-map-of-every-possible-dna-letter-change-in-the-human-genome/
-   Demo: https://youtu.be/b2qw3rDNX0Q
